# OctoAcme Project Management Process Docs

This README provides a brief summary of OctoAcme's project management processes and links to each process document stored in this repository's docs/ folder. It is intended as a single entry point to help team members and new hires discover, navigate, and apply the documented processes.

Summary of OctoAcme project management processes:

- Project Management Overview: high-level principles and goals for how projects are run at OctoAcme, core roles, and key artifacts.
- Project Initiation: how projects are proposed, evaluated, and approved (one‑pager, stakeholders, go/no‑go).
- Project Planning: planning artifacts, backlog practices, estimation, Definition of Done, and risk/dependency management.
- Execution and Tracking: sprint cadence, project board workflow, PR conventions, CI requirements, and progress reporting.
- Risks and Communication: how risks are identified, recorded, and escalated, and stakeholder communication cadence.
- Release and Deployment: release checklist, deployment responsibilities, verification, and rollback guidance.
- Retrospective and Continuous Improvement: how teams capture lessons, action items, and feed improvements back into process docs.
- Roles and Personas: responsibilities and expectations for common project roles (PM, PdM, Developers, QA, Stakeholders).

How to use this folder

- Keep process documents up to date in the docs/ folder. When a project needs project-specific variations, add a short 'project-<name>.md' in the repo and link back to these canonical docs.
- Add any process-specific files that Copilot Spaces should use into `.copilot/` within the project repository.

Acceptance criteria (for maintainers)

- README exists at docs/README.md and links to each process doc in this folder.
- Links resolve to the correct files.
- Content aligns with the project's existing process documentation and improves discoverability.
